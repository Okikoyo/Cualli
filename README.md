# Cualli — Café de buenas noticias

Portal de pedidos directos de Cualli, la cafetería mexicana donde cada taza trae algo bueno que contar.

- **Página:** se publica con GitHub Pages desde `index.html`.
- **Datos:** las cuentas, los pedidos, las buenas noticias y la cuponera viven en Supabase (proyecto `ugujojnogemlbfemkedk`), no en este repositorio.
- **Descuentos:** compartir una buena noticia da 5%, lo bueno de una mala noticia 7% y una buena noticia con evidencia 10%. Solo la primera buena noticia del día da descuento.
- **Cuponera:** después del café número 10, el siguiente es gratis; solo compras directas.

La página usa únicamente la clave publicable de Supabase, pensada para el navegador. La clave secreta nunca va en este repositorio.
